# Telco-Marktforschung

Sammlung eines CSV-Datensatzes und einer Markdown-Analyse zu deutschen Telekommunikationsanbietern. Dieses Repository enthält Dokumentation und Daten, keine ausführbare Anwendung.

## Inhalte

- [Datensatz: provider_metrics.csv](data/provider_metrics.csv) – Anbieter, Marktanteile, NPS, KI-Reife, CX, Innovation, Preisindex, B2B-Anteil, Automatisierung und Cloud-Partnerschaften.
- [Marktanalyse](reports/marktanalyse.md) – SWOT-Betrachtungen sowie Trend- und Gap-Analyse.

## Verwendung

Den Bericht direkt auf GitHub oder in einem Markdown-Editor lesen. Die CSV-Datei kann in einem Tabellenprogramm oder einer Analyseumgebung geöffnet werden; sie verwendet Kommas als Feldtrenner. Eine Paketinstallation oder ein Build ist nicht erforderlich.

## Datenqualität

Die README beschreibt den vorhandenen Datenbestand. Aktualität, Erhebungszeitraum und externe Quellen der Kennzahlen sind dadurch nicht bestätigt. Bei Ergänzungen Quelle, Bezugsdatum, Einheit und Berechnungsmethode mit dokumentieren und den Bericht mit den Daten abgleichen.

## Beiträge

Datenkorrekturen und Änderungen am Bericht gemeinsam in einem Pull Request erläutern.
